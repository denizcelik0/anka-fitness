# Anka Fitness

Sakarya Erenler için premium siyah-kırmızı temalı fitness salonu web sitesi.

## Teknolojiler

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Başlatma

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## Üretim

```bash
npm run build
npm start
```

## İçerik

İletişim, paket fiyatları ve diğer sabitler `src/lib/site.ts` dosyasından yönetilir.
